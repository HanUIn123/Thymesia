# Thymesia 팀 프로젝트 (DirectX11 기반 3D 게임)

## 🎮 개요
- Thymesia 스타일의 보스전 중심 액션 게임
- 팀원 6명 참여, 그중 나는 **맵툴 / 네비게이션 / 연출 / 상호작용 / 인스턴싱 / 아이템 시스템**을 담당
- **C++ / DirectX11 / HLSL / ImGui 기반 자체 엔진 프로젝트**

## 🛠️ 개발 환경
- 언어: C++
- 그래픽 API: DirectX 11, HLSL
- 플랫폼: Windows API
- 개발 도구: Visual Studio, GitHub, ImGui

## ✨ 주요 구현 기능

### 1. Navigation 시스템 (맵툴 제작 및 이동 가능 영역 처리)
- **픽셀 피킹** 기반 셀 생성 (툴에서 클릭한 위치를 월드 좌표로 변환)
- **정점 시계방향 교정**, 셀 인접 관계/경계선 판정
- 오브젝트가 **Navigation Cell 내부에서만 이동** 가능하도록 구현
- **층간 이동** 구현 (셀 y값 기반 위치 보정)

### 2. Geometry Shader 연출
- **Idle 상태**에서 포자가 꿈틀거리게 하는 사인파 기반 진동
- **피격 시 파편화**: 8방향 분할 + 고유 난수 방향 + 로드리게스 회전 적용
- **돌 파편 연출**: 중앙에서 원형 퍼짐, 상승 및 중력 기반 낙하 구현

### 3. Item 시스템
- `CItemMgr` 기반 **아이템 등록 / 드롭 / 획득 / 복원 관리**
- **베지어 곡선 기반 아이템 드롭 궤적** 구현
- **아이템 렌더링 효과**: UV 흔들림 + 팽창/수축 이펙트
- **씬 전환 시 아이템 정보 복원 처리** (댕글링 포인터 방지 포함)

### 4. 상호작용 시스템
- **림라이트 셰이더 효과**로 상호작용 가능한 오브젝트 강조
- **Lock-On 시스템**: 플레이어 ↔ 몬스터 간 라인 연결 + UV 흐름 연출
- **상호작용 UI 버튼**: 월드좌표 → 화면 HUD 위치 변환 로직 구현

### 5. 메쉬 인스턴싱 + 컬링 최적화
- `CGroundObject` 기반 인스턴싱 구조 설계
- 각 인스턴스의 월드행렬 → `VTX_MODEL_INSTANCE` 구조체로 GPU 전송
- **CPU 프러스텀 컬링** 구현 (AABB → 절두체 검사 → 인스턴스 선별)
- **버퍼 생성 → 바인딩 → DrawIndexedInstanced() 호출**로 렌더링 최적화

## 📁 폴더 구조
- `Client`: 게임 클라이언트 로직 (UI, 연출, 플레이어 등)
- `Engine`: 공통 엔진 로직 (렌더링, 충돌, 셰이더, 오브젝트 관리 등)
