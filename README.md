# Thymesia 팀 프로젝트 (DirectX11 기반 3D 게임)

## 🎮 개요
- Thymesia 스타일의 보스전 중심 액션 게임
- 3인 팀 프로젝트 (맵툴, 보스 연출, 디졸브 등 개별 담당 구분)

## 🛠️ 개발 환경
- 언어: C++
- 엔진: DirectX 11
- 툴: Visual Studio, GitHub

## ✨ 주요 구현 기능
- 실시간 맵툴 제작 및 에디팅 기능
- 보스 등장 연출 (경고 UI → 디졸브 등장 → 체력 UI 연동)
- Geometry Shader 기반 파괴 연출
- 캐릭터 상태머신 및 공격 콤보 시스템
- 네비게이션 시스템 (셀 기반 충돌 + 경계선 시각화)
